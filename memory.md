## Décisions permanentes
- **Preuve par mutation obligatoire** (2026-08-07, #744) : tout test de `tests/vanilla/` doit être validé en **cassant le code réel** (rouge attendu) puis en restaurant **avant commit**, et la preuve documentée dans la PR/CHANGELOG (« comportement neutralisé → N tests rouges »). Un test qui passe ne prouve rien s'il ne peut pas échouer. C'est cette méthode qui a fait remonter 19 défauts que la CI validait en vert.
- **Sécurité innerHTML** (2026-07-27, #758) : toute donnée consumer atterrissant dans un attribut passe par la **construction de nœuds** (`createElement`/`setAttribute`/`textContent`), jamais par `escapeHTML` — qui n'échappe pas les guillemets. Les URL consumer passent par `safeUrl()`. Gate CI `bin/check-innerhtml.js` bloquant, dérogations `// ds-allow-innerhtml: <raison>` motivées. Règle complète : `DS-PRINCIPLES.md` §11.
- **DS = préprod-only** (2026-07-23) : servi UNIQUEMENT sur `design-system.miklaw.fr` (Coolify, 100% Authentik-gated) ; `design-system.msyx.fr` N'EXISTE PAS (décommissionné, CLAUDE.md corrigé). Release note = **alimenter+dater+versionner directement** (pas de `[Unreleased]` qui traîne, pas de promotion prod). Ne jamais dire « livré » sans vérifier que l'user peut le VOIR (URL réelle + auth + commit déployé FINISHED). Cf. [[reference-ds-deploy-preprod-only]].
